# Nostra-E-Commerce-Project
A responsive fashion e-commerce website built with HTML, CSS, and JavaScript, featuring product search, filtering, and a modern user-friendly interface.

Nostra is a responsive e-commerce website built using HTML, CSS, and JavaScript. It features a modern fashion-focused design with multiple pages and interactive product browsing functionality.

Features
* Responsive Home, Collections, and Contact pages
* Product search functionality
* JavaScript-based product filtering
* Responsive navigation menu
* Modern and mobile-friendly UI
* Newsletter subscription and contact form
* Responsive design for Mobile, Tablet, and Desktop
  
Technologies Used
* HTML5
* CSS3
* JavaScript
